1 Introduction and Problem Statement

Agricultural commodity prices in India change over time because of supply and demand, seasons, weather and market conditions. These changes make it hard for farmers, traders and consumers to plan. This project studies historical market prices and builds time-series models to forecast future prices.

2 Objectives

  1. Explore historical minimum, modal and maximum prices of a commodity.
  2. Identify yearly trends and seasonal patterns.
  3. Compare three forecasting models: Baseline, Moving Average and SARIMA.
  4. Evaluate the models with MAE, RMSE and MAPE, and forecast one year ahead.

3 Dataset

  • Name: Daily Commodity Prices India
  • Source: Kaggle (originally from India’s AGMARKNET system)
  • URL: https://www.kaggle.com/datasets/khandelwalmanas/daily-commodity-prices-india
  • Content: daily wholesale market prices (Rs per quintal) by state, district, market, commodity and variety.
  • Used here: yearly files for 2015 to 2025.

A helper builds a continuous monthly series for one price column. Missing months are filled by linear interpolation.

prepare_series <- function(data, price_column) {
  s <- data %>%
    group_by(Month) %>%
    summarise(Price = mean(.data[[price_column]], na.rm = TRUE),
              .groups = "drop") %>%
    filter(is.finite(Price), Price > 0) %>%
    arrange(Month) %>%
    complete(Month = seq(min(Month), max(Month), by = "month")) %>%
    arrange(Month)
  s$Price <- zoo::na.approx(s$Price, na.rm = FALSE)
  s$Price <- zoo::na.locf(s$Price, na.rm = FALSE)
  s$Price <- zoo::na.locf(s$Price, fromLast = TRUE, na.rm = FALSE)
  s
}

7 Prediction Models

Three models are compared. The last 12 months are held out as a test set; the models are trained on the earlier months.

  • Baseline: every future month equals the last observed price.
  • Moving Average: average of the last 3 months, rolled forward.
  • SARIMA: seasonal ARIMA with a 12-month cycle, fitted on log prices with forced seasonal differencing (auto.arima, D = 1, lambda = 0).

The model with the lowest RMSE on the test set is refitted on all data to forecast the selected year.

fit_sarima <- function(values, start_month) {
  s <- ts(values, start = c(year(start_month), month(start_month)),
          frequency = 12)
  fit <- tryCatch(auto.arima(s, seasonal = TRUE, D = 1, lambda = 0),
                  error = function(e) NULL)
  if (is.null(fit))
    fit <- tryCatch(auto.arima(s, seasonal = TRUE, lambda = 0),
                    error = function(e) NULL)
  fit
}

ma_forecast <- function(history, h, window = 3) {
  out <- numeric(h)
  for (i in seq_len(h)) {
    out[i] <- mean(tail(history, window))
    history <- c(history, out[i])
  }
  out
}

metric_row <- function(actual, predicted, model) {
  e  <- actual - predicted
  ok <- is.finite(predicted) & actual != 0
  data.frame(Model = model, MAE = mean(abs(e)), RMSE = sqrt(mean(e^2)),
             MAPE = if (any(ok)) mean(abs(e[ok] / actual[ok])) * 100 else NA)
}

forecast_series <- function(data, price_column, year_to_predict) {
  s      <- prepare_series(data, price_column)
  stopifnot(nrow(s) >= 36)
  values <- s$Price
  start  <- min(s$Month)
  last_m <- max(s$Month)
  horizon <- (year_to_predict - year(last_m)) * 12 + (12 - month(last_m))
  stopifnot(horizon >= 1)

  train <- head(values, length(values) - 12)
  test  <- tail(values, 12)

  base_t  <- rep(tail(train, 1), 12)
  ma_t    <- ma_forecast(train, 12)
  fit_t   <- fit_sarima(train, start)
  sarima_t <- if (is.null(fit_t)) rep(NA_real_, 12) else
    as.numeric(forecast(fit_t, h = 12)$mean)

  metrics <- bind_rows(metric_row(test, base_t, "Baseline"),
                       metric_row(test, ma_t, "Moving Average"),
                       metric_row(test, sarima_t, "SARIMA"))
  ok   <- metrics[is.finite(metrics$RMSE), ]
  best <- ok$Model[which.min(ok$RMSE)]

  pred <- switch(best,
    "Baseline"       = rep(tail(values, 1), horizon),
    "Moving Average" = ma_forecast(values, horizon),
    "SARIMA"         = as.numeric(forecast(fit_sarima(values, start),
                                           h = horizon)$mean))

  all_f <- data.frame(Month = seq(last_m %m+% months(1), by = "month",
                                  length.out = horizon),
                      Price = pmax(pred, 0.01))
  list(forecast = filter(all_f, year(Month) == year_to_predict),
       metrics = metrics, best = best,
       holdout = data.frame(Month = tail(s$Month, 12), Actual = test,
                            Baseline = base_t, `Moving Average` = ma_t,
                            SARIMA = sarima_t, check.names = FALSE))
}

9 Conclusion

  • The 132-month history of Brinjal in Telangana shows a clear seasonal pattern, with the highest average prices in Oct and the lowest in Mar.
  • On the 12-month test set, SARIMA had the lowest RMSE for the modal price (8.46 Rs/kg).
  • The advantage of SARIMA over the Baseline can be small, so forecasts are estimates and not guarantees. Accuracy also falls for years further from the last observed data.
  • Limitations: the test uses only 12 months, missing months are interpolated, and weather or policy effects are not modelled.
  • Future work: add rainfall and arrival quantities, try other models, and evaluate with rolling-origin cross-validation.
